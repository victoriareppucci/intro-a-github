# Introducción a Señales y Sistemas — Material

Repositorio con la notebook y datos usados en la clase de repaso de Señales y Sistemas.

## Contenido
- `01_Repaso_señales_y_sistemas.ipynb` — Notebook principal con ejemplos y ejercicios.
- `ecg50hz.mat` — Señal ECG de ejemplo en formato MATLAB (.mat).
- `requirements.txt` — Dependencias mínimas para ejecutar la notebook.

## Requisitos
Instala las dependencias listadas en `requirements.txt`.

## Instalación (entorno local)
1. Crear/activar un entorno virtual (recomendado):

```bash
python -m venv .venv
source .venv/bin/activate
```

2. Instalar dependencias:

```bash
pip install -r requirements.txt
```

3. Seleccionar kernel de nuestro venv.

4. Ejecutar las celdas de la notebook.
